# Open Pulse Docs Site

This folder contains the Docusaurus documentation source for Open Pulse.

## Local development

From `docs-site/`:

```bash
pnpm install
pnpm start
```

## Build and link checks

From `docs-site/`:

```bash
pnpm build
```

`pnpm build` runs Docusaurus production build and fails on broken links based on the project configuration.
