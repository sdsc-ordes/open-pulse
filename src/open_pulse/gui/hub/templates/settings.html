How this works

Every key you save here lives in your browser only, under localStorage["op:hub:secrets:v1"]. The Projects / Databases pages read these at page load and include them in the request body when the hub needs to call an upstream that requires auth (the applier sidecar, a Basic-auth SPARQL endpoint, …). Nothing gets written to the hub's SQLite or DuckDB. Clearing your browser data (or hitting Clear all) wipes them.

Keys

Agent model

The default model the agent chat and the Databases assistant use. Leave on Hub default to follow the server. Click Load available models to list what your RCP key (above) can access, then pick one.

RDF graph

Which named graph the hub's RDF reads from on entity pages (facts, citations, related-in-graph edges). Leave on Store default to keep current behaviour. Click Load graphs to list the snapshots in the SPARQL store, then pick one — it applies to your browser only.

Browser-local backup

Everything the hub keeps in your browser — saved keys, query tabs, theme — under localStorage["op:hub:*"] and op-hub-theme. Download a JSON snapshot to move to another machine, restore from one, or wipe the lot.
