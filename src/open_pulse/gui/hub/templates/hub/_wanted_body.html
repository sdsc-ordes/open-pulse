How the hub works

The hub identifies resources by their URL. To reference any object on the public web, type its address into the path after /hub/:

  • /hub/github.com/<owner>/<repo>
  • /hub/zenodo.org/records/<id>
  • /hub/ror.org/<rorid>
  • /hub/infoscience.epfl.ch/entities/publication/<id>
  • /hub/huggingface.co/<model-or-org>
