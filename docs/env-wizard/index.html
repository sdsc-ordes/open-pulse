Open Pulse — infra/.env wizard

Answer the questions on the left; the generated file appears on the right. Everything runs in your browser — no values are sent anywhere.

1 · What do you want to deploy?

Pick the profiles you intend to bring up. The wizard only asks for credentials needed by what you select.

2 · Where will state live on disk?

Use an absolute path. The data dir is the repo root + /data by default; the host path is the repo root.

Windows detected. Use /c/... or /d/... form (Docker Desktop's translation), not C:\ — the cli orchestrator container's identity-bind needs a Linux-valid path.

3 · Image source

Pull pre-built images from GHCR (recommended) or pin a locally-built tag for development.

4 · GitHub credentials

Generate a classic PAT with at least public_repo read scope. The same token can be reused across all three slots.

5 · Extractor LLM provider

The v2 extractor's rule_based runtime doesn't need an LLM key. Only fill this if you'll switch to LLM-backed extraction later.

6 · Auto-generated tokens

Every secret is generated locally with crypto.getRandomValues. Click any "↻" to regenerate. OpenSearch needs a stronger password to satisfy its security plugin's regex — that one's slightly different in shape.
