About this dashboard

This is the entry-point UI for the Open Pulse stack. Every tab is a self-contained tool that talks to a service over HTTP — credentials are entered in the browser and cached in localStorage. The server only sees the output of the tool, never the user's keys.

Planned tabs: SPARQL explorer (ad-hoc queries against the same store), crawler runner (submit + poll BFS jobs), pipeline status (last quest run + artifact links).
